Acerca de ÓRBITA

ÓRBITA · Sistema de bienestar de tripulación. Esta versión guarda los datos localmente en el navegador de este dispositivo.

No introduzcas información que no quieras almacenar en este dispositivo. Esta versión no sincroniza datos con un servidor.

Zona de seguridad

Puedes eliminar todos los registros y datos personales guardados en este navegador. Esta acción no se puede deshacer.
